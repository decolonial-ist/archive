Сдача оружия должна быть произведена добровольно 9 сентября с доставкой оружия Грозный. Необходимое оружие для самообороны аулу Гойты будет оставлено»

Сейчас веду переговоры с представителями. Дело ведется через отпущенных мною заложников... Пусть 15 часов появятся аэропланы, но не бьют. Для эффекта пусть прибудут штук 6—7»
