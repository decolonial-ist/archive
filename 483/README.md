- **[Разоружение Чечни: войсковая операция с артобстрелами и бомбардировками аулов (1925)](https://decolonial.ist/campaigns/C1177/#procedures) — техника [Принудительное разоружение](https://decolonial.ist/techniques/T0155/)**

- **[Разоружение Чечни: войсковая операция с артобстрелами и бомбардировками аулов (1925)](https://decolonial.ist/campaigns/C1177/#procedures) — техника [Захват заложников](https://decolonial.ist/techniques/T0099/)**

Они страшно боялись самолета. Только после того, как по селу выпустили несколько снарядов с тем, чтобы без разрушения домов жители почувствовали его силу, старики сказали, в каком ущелье скрывается Гоцинский»
